# QuantJunkrat fusion submission

This ZIP contains the required `evaluation_wrapper.py`, runtime Python modules, prebuilt CUDA extensions, and an offline quantization codebook. It intentionally excludes model weights, dataset files, benchmark outputs, and local self-test scripts. The official worker should provide `benchmark.py`, `Qwen3-VL-2B-Instruct`, and `data`.

Selected submission profile: `clamp160`.

Default runtime path: no-resize processor path (only alignment padding when required by the model) + FastMinimalQwen3VLModel + static KV cache + bundled rowwise-Q8 codebook + Acext speed+error auto-gated prefill A8W8 gate/up + fused Sage Q/K INT8 + BF16 V mixed-KV decode from the first generated token + runtime Q8 text decode + default-enabled W4A16 gate_up/down/qkv/o_proj for all lengths + default-enabled W4A16 lm_head argmax via native persistent CUDA kernels + fused down->norm->QKV chain. The decode qkv and o_proj W4A16 GEMVs default to the unsplit (1 warp/row, AWQ-interleaved, persistent) kernels, which raise achieved DRAM bandwidth vs the split-2 path (~+23%/+22% isolated, ~+4.8% end-to-end decode throughput) at numerically-equivalent greedy output. This package bakes `JUNKRAT_PROCESSOR_MIN_VISUAL_TOKENS=128` and `JUNKRAT_PROCESSOR_MAX_VISUAL_TOKENS=160`. Conservative mode can still disable individual W4 weights (`JUNKRAT_ENABLE_W4A16_*`), revert the unsplit GEMVs (`JUNKRAT_W4A16_QKV_UNSPLIT=0`, `JUNKRAT_W4A16_O_PROJ_UNSPLIT=0`), or restore `JUNKRAT_W4A16_DOWN_ONLY_128=1`. Routed image resizing, Sage half-layer fusion, true W8A8 decode/lm_head, Acext A8W8/A16W8/A16W4 decode lm_head variants, the legacy SmoothQuant+GPTQ-derived codebook, W4A4 speculative, and full INT8 V variants remain opt-in.

TTFT: the prefill CUDA graph now actually fires (it had silently never replayed because the init pre-capture enumerated unreachable grid dims 48/64 and a wrong non-visual seq bucket). `_common_vision_grids` enumerates the real clamped grids and the pre-capture matches the real (grid, 224-bucket, span) key, so the full vision+text prefill graph replays for every clamped image (clamped TTFT ~22ms eager -> ~18ms, bit-identical answers, decode throughput unchanged). A grid-independent decoupled text-decoder graph (`AICAS_DECOUPLED_PREFILL_GRAPH`) is the always-fires fallback. Accuracy: W4A16 weights use a calibration-free MSE-optimal per-group scale (`JUNKRAT_W4A16_MSE_SCALE`, default on) instead of naive max-scaling — ~14% lower W4 reconstruction error at zero inference cost (the GEMV kernel only multiplies by the stored scale). New runtime modules `triton_act_quant.py`, `triton_vision_rope.py`. Disable via `AICAS_PREFILL_GRAPH_PRECAPTURE=0` / `JUNKRAT_DISABLE_PREFILL_GRAPHS=1` / `JUNKRAT_W4A16_MSE_SCALE=0`.

## Offline quantization codebook

`bundled_quantization/rowwise_q8/quant_codebook.safetensors` is enabled by default. It is regenerated from the dense checkpoint with rowwise max-abs Q8 scales for text Q/K/V/O and gate/up/down layers, excluding vision, embeddings, and the lm_head runtime-packed path. Int8 buffers are attached only when `JUNKRAT_ENABLE_W8A8_DECODE=1` or `JUNKRAT_ENABLE_W8A8_LM_HEAD=1` is requested; disabled A8 targets are pruned after auto-profiling so the packed-Q8 path avoids W8A8 buffer overhead. The previous SmoothQuant+GPTQ W8A8 codebook remains packaged under `bundled_quantization/w8a8/` only for explicit ablation because it caused repetitive long-answer drift.
