# 当前已验证成功方案（A6000 / vLLM / AWQ）

> 说明：按仓库约束，仅允许修改 `evaluation_wrapper.py` 和 `_base` 目录，因此本文档写入 `_base/成功.md`。

## 1. 当前最佳配置

### 1.1 吞吐最优（推荐默认提交候选）

- 模型：`awq_experiments/qwen3vl_awq_w4a16_textonly_s32`
- 量化：`compressed-tensors`（AWQ）
- KV cache：`auto`
- 文本 attention backend：`TRITON_ATTN`
- MM encoder backend：`TORCH_SDPA`
- GPU：A6000
- 样本数：20

结果：
- **TTFT：47.95 ms**
- **Throughput：267.79 tok/s**
- **类别命中率：40.00%（20 样本，8/20）**

结果文件：
- `result_awq20_triton_sdpa_autokv_gpu1.json`

### 1.2 TTFT 最优

- 文本 attention backend：`FLASHINFER`
- MM encoder backend：`TORCH_SDPA`
- 其他条件同上

结果：
- **TTFT：41.66 ms**
- **Throughput：261.97 tok/s**
- **类别命中率：40.00%**

结果文件：
- `result_awq20_flashinfer_sdpa_autokv_gpu1_fixcuda.json`

## 2. 推荐启动命令（基于 benchmark.py）

### 2.1 吞吐最优：TRITON_ATTN + MM TORCH_SDPA

```bash
source /data/songbinbin/minicoda/etc/profile.d/conda.sh
export NVCC_PREPEND_FLAGS="${NVCC_PREPEND_FLAGS:-}"
conda activate aicas_vllm_fp8

export CUDA_VISIBLE_DEVICES=1
export NCCL_SO=/data/songbinbin/minicoda/envs/aicas_vllm_fp8/lib/python3.10/site-packages/nvidia/nccl/lib/libnccl.so.2
export LD_PRELOAD=$NCCL_SO
export VLLM_NCCL_SO_PATH=$NCCL_SO
export VLLM_ENABLE_V1_MULTIPROCESSING=0
export VLLM_WORKER_MULTIPROC_METHOD=spawn

export AICAS_USE_MINIMAL_VLLM_WRAPPER=1
export AICAS_ENABLE_VLLM_BRIDGE=1
export AICAS_VLLM_PREQUANT_METHOD=compressed-tensors
export AICAS_VLLM_DTYPE=float16
export AICAS_VLLM_MAX_MODEL_LEN=1024
export AICAS_VLLM_SKIP_MM_PROFILING=1
export AICAS_VLLM_GPU_MEMORY_UTIL=0.20
export AICAS_VLLM_KV_CACHE_DTYPE=auto
export AICAS_VLLM_ATTENTION_BACKEND=TRITON_ATTN
export AICAS_VLLM_MM_ENCODER_ATTN_BACKEND=TORCH_SDPA

python benchmark.py \
  --model-path ./awq_experiments/qwen3vl_awq_w4a16_textonly_s32 \
  --dataset-path ./data \
  --output result_awq20_triton_sdpa_autokv_gpu1.json \
  --num-samples 20
```

## 4. 已验证负收益或不推荐项

### 4.1 use_prefill_decode_attention

结果文件：
- `result_awq20_triton_sdpa_prefilldecode_gpu1.json`

结果：
- TTFT：55.83 ms
- Throughput：264.15 tok/s

结论：**负收益，不建议开启**。

### 4.2 关闭 prefix caching

结果文件：
- `result_awq20_triton_sdpa_noprefix_gpu1.json`

结果：
- TTFT：56.18 ms
- Throughput：253.63 tok/s

结论：**明显负收益，必须保留 prefix caching**。

### 4.3 max_model_len=768

结果文件：
- `result_awq20_triton_sdpa_len768_gpu1.json`

结果：
- TTFT：55.13 ms
- Throughput：260.27 tok/s

结论：**比 1024 更差**。

### 4.4 FLASHINFER 路线中的额外开关

#### 开启 flashinfer prefill
- 文件：`result_awq20_flashinfer_sdpa_prefillon_gpu1.json`
- 结果：TTFT 50.48 ms / Throughput 250.61 tok/s
- 结论：**负收益**

#### 开启 use_trtllm_attention=1
- 文件：`result_awq20_flashinfer_sdpa_trtllm_gpu1.json`
- 结果：TTFT 57.93 ms / Throughput 258.17 tok/s
- 日志：`TRTLLM attention is not supported on this platform`
- 结论：**当前平台不支持，且结果更差**

#### 同时开启 prefill + trtllm
- 文件：`result_awq20_flashinfer_sdpa_prefillon_trtllm_gpu1.json`
- 结果：TTFT 48.42 ms / Throughput 259.87 tok/s
- 结论：**仍不如纯 FLASHINFER 基线**

## 5. speculative decoding 探索结果

结果：

### 5.2 suffix speculative decoding

结果：未跑通

报错：
- `ImportError: Arctic Inference is required for suffix decoding.`
- 需要：`pip install arctic-inference==0.1.1`

结论：**当前环境默认不可用**。

## 6. 关于 FP8 KV cache 的结论

当前 A6000 + vLLM 0.20.1 环境下：

- `FLASH_ATTN + fp8 kv cache`：不兼容
- `TRITON_ATTN + fp8 kv cache`：会触发 fp8 Triton 类型/架构兼容问题
- 因此 **AWQ 主路径建议维持 KV cache=auto**，不要开 FP8 KV

## 7. 当前最终建议

### 7.1 如果以吞吐为核心目标

使用：
- `TRITON_ATTN + MM TORCH_SDPA`

### 7.2 如果以 TTFT 为核心目标

使用：
- `FLASHINFER + MM TORCH_SDPA`

### 7.3 当前最稳妥推荐

若只有一套默认配置，优先建议：

```bash
AICAS_VLLM_ATTENTION_BACKEND=TRITON_ATTN
AICAS_VLLM_MM_ENCODER_ATTN_BACKEND=TORCH_SDPA
AICAS_VLLM_PREQUANT_METHOD=compressed-tensors
AICAS_VLLM_KV_CACHE_DTYPE=auto
AICAS_VLLM_MAX_MODEL_LEN=1024
AICAS_VLLM_ENABLE_PREFIX_CACHING=1
AICAS_VLLM_SKIP_MM_PROFILING=1
AICAS_VLLM_GPU_MEMORY_UTIL=0.20
```

因为它在当前所有已验证配置里：
- 吞吐最高
- 精度不劣化
- 兼容性最好
- 环境要求低于 FLASHINFER
