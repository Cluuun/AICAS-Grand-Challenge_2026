# 2026-06-16 KV260 复赛最终视频演示流程

## 演示目标

视频展示从 KV260 板卡真实运行、SDF5 PL overlay 加载、PL 单算子 smoke，到 SmolVLM2 图文推理输出和 PL replace trace 的完整流程。

最终演示使用稳定提交口径：

```text
runtime: /home/ubuntu/aicas/mnn_cacheexp_20260601/bin/aicas_mnn_server
overlay: SDF5 KV260 direct-runtime overlay
PL replace shape: 1024x64x1024
PL replace limit: 8
不使用 XRT / ZOCL / xclbin
不使用实验性 aicas_mnn_server.stream_demo
```

注意：演示脚本采用稳定 server 完成一次 VLM 请求后进行 typewriter 风格逐字显示；这是为了视频观感稳定。计分与复现主线仍是稳定 MNN server + SDF5 PL8 replace。

## 推荐视频结构

### 1. 板卡和系统状态

镜头内容：

- 拍 KV260 实物、SD 卡、供电、网线。
- 终端 SSH 登录板卡。
- 展示系统、内核和 FPGA manager。

命令：

```bash
ssh ubuntu@192.168.137.102

hostname
uname -a
cat /proc/device-tree/model
df -h / /home/ubuntu/aicas_data
ls /sys/class/fpga_manager
```

希望拍到：

```text
xilinx-kv260-starterkit-20231
Linux ... 6.1.5-xilinx-v2023.1 ...
/sys/class/fpga_manager/fpga0
```

### 2. 加载最终 SDF5 overlay

命令：

```bash
sudo bash /home/ubuntu/aicas/mnn_cacheexp_20260601/scripts/kv260_load_sdf5_configfs_safe.sh \
  /home/ubuntu/aicas/stage_hw/sdf5/system.bit.bin \
  /home/ubuntu/aicas/stage_hw/sdf5/pl_sdf5_kvfit_kv260_uio_only.dtbo
```

希望拍到：

```text
FPGA state: operating
Overlay status: applied
/sys/class/uio/uio4 name=sdf4-4-linear addr=0x0000000096000000 size=0x0000000000001000
LANE0_MAGIC=0x53444635
```

### 3. 跑提交 shape 的 PL 单算子 smoke

命令：

```bash
sudo /home/ubuntu/aicas/mnn_cacheexp_20260601/bin/sdf5_kvfit_batch_test \
  --quick --mnn-only --case mnn_block_1024x64x1024
```

希望拍到：

```text
LINEAR mnn_block_1024x64x1024 M=1024 K=64 N=1024 PASS
SDF5_KVFIT_BATCH_TEST PASS
```

说明：

```text
该 smoke 对应最终提交 allowlist 中真实替换的 shape = 1024x64x1024。
```

### 4. 运行稳定 VLM 可视化演示

推荐命令：

```bash
AICAS_VISUAL_MAX_TOKENS=64 \
AICAS_VISUAL_TYPEWRITER_DELAY=0.015 \
bash /home/ubuntu/aicas_data/stream_demo_20260616/scripts/kv260_stable_pl8_visual_demo.sh
```

更稳更快的录制命令：

```bash
AICAS_VISUAL_MAX_TOKENS=32 \
AICAS_VISUAL_TYPEWRITER_DELAY=0.02 \
bash /home/ubuntu/aicas_data/stream_demo_20260616/scripts/kv260_stable_pl8_visual_demo.sh
```

该脚本会自动执行：

```text
1. 加载 SDF5 overlay
2. 打印 UIO 状态
3. 运行 mnn_block_1024x64x1024 PL smoke
4. 启动稳定 aicas_mnn_server
5. 发送图文请求
6. 逐字显示 Assistant 输出
7. 汇总 PL trace
```

希望拍到：

```text
AICAS KV260 stable PL8 visual demo
--- load SDF5 overlay ---
Overlay status: applied
--- SDF5 submission-shape smoke ---
SDF5_KVFIT_BATCH_TEST PASS
--- start stable submission server ---
AICAS MNN server listening on 0.0.0.0:8263
--- visual VLM response ---
Assistant: ...
--- PL trace summary ---
matmul_replace_ok_count=8
pl_linear_packed_ok_count=8
replace_shapes=['1024x64x1024']
DONE OUT=/home/ubuntu/aicas_data/stream_demo_20260616/runs/...
```

### 5. 展示最终 JSON 和提交口径

命令：

```bash
python3 - <<'PY'
import json
p = "/home/ubuntu/aicas_data/submission_refs/aicas_submission_prefix_delta_pl8_retest_20260607.json"
try:
    data = json.load(open(p, encoding="utf-8"))
except FileNotFoundError:
    p = "/home/ubuntu/aicas/mnn_cacheexp_20260601/results/aicas_submission_prefix_delta_pl8_retest_20260607.json"
    data = json.load(open(p, encoding="utf-8"))
print("json:", p)
print("mode:", data.get("mode"))
print("prefill:", data.get("throughput", {}).get("prefill_speed_tps"))
print("decode:", data.get("throughput", {}).get("decode_speed_tps"))
print("tokens_per_joule:", data.get("energy", {}).get("tokens_per_joule"))
print("ttft_slope:", data.get("ttft", {}).get("slope_ms_per_char"))
print("pl_trace:", data.get("pl_trace_summary"))
PY
```

如果板上没有该 JSON，可在视频中展示提交包内文件：

```text
results/aicas_submission_prefix_delta_pl8_retest_20260607.json
```

## 不建议录制的路径

不要使用：

```text
/home/ubuntu/aicas_data/stream_demo_20260616/bin/aicas_mnn_server.stream_demo
```

原因：

```text
实验性 true SSE streaming runtime 曾出现卡死/连接断开；最终提交和视频演示应使用稳定 aicas_mnn_server。
```

## 录制检查清单

录制前确认：

```bash
ps -ef | grep -E "aicas_mnn_server|mnn_ttft|mnn_throughput|mnn_energy" | grep -v grep || true
systemctl list-units --type=service --state=running "aicas-final*" --no-pager || true
df -h / /home/ubuntu/aicas_data
```

如果有残留 server：

```bash
sudo pkill -f '[a]icas_mnn_server' || true
```

replace_shapes=['1024x64x1024']
