# SmolVLM2 KV260 PYNQ 上板测试命令与结果

本文档用于技术报告记录。测试目录为板上：

```text
/root/jupyter_notebooks/pynq_smolvlm2
```

## 0. 公共前置

```bash
cd /root/jupyter_notebooks/pynq_smolvlm2
export XILINX_XRT=/usr
PY=/usr/local/share/pynq-venv/bin/python
```

## 1. 吞吐率 Throughput

测试 prefill 和 decode 阶段的吞吐率。

```bash
$PY eval/throughput_bench.py
```

> ⚠️ 不要加 `--max-new-tokens-auto`，否则 `prefill_tps` 会被长 decode 稀释成假值（约 4.92）。

| 指标 | 结果 |
| --- | ---: |
| `prefill_speed_tps` | 24.29 |
| `decode_speed_tps` | 14.28 |

## 2. 能效 Energy

长生成，忽略 EOS，PMBus 采样。

```bash
$PY eval/energy_bench.py
```

报告结果：

| 指标 | 结果 |
| --- | ---: |
| `tokens_per_joule` | 1.6141 |
| `completion_tokens` | 648 |
| `average_power_w` | 4.96 |
| `total_energy_j` | 401.45 |
| `inference_duration_s` | 80.89 |

## 3. TTFT

官方 2 图 x 3 prompt，warmup 后做线性拟合。

```bash
$PY eval/ttft_bench.py --warmup
```

报告结果：

| 指标 | 结果 |
| --- | ---: |
| `slope_ms_per_char` | 1.538 |
| `intercept_ms` | 18476 |
| `per_image[large].slope_ms_per_char` | 1.526 |
| `per_image[large].intercept_ms` | 18725 |
| `per_image[small].slope_ms_per_char` | 1.550 |
| `per_image[small].intercept_ms` | 18226 |

> 说明：xlong case 报错为预存数据问题，非本次测试回归。

## 4. 精度 Accuracy 参考


| 指标 | 结果 |
| --- | ---: |
| `ratio_accuracy` | 0.43 |
| `n_correct` | 13 |

## 5. 脚本说明

| 脚本 | 作用 |
| --- | --- |
| `eval/throughput_bench.py` | 吞吐率测试脚本，测试模型在 prefill 和 decode 阶段的 token 处理速度。报告中主要引用 `prefill_speed_tps` 和 `decode_speed_tps`。 |
| `eval/energy_bench.py` | 能效测试脚本，在长生成过程中采集功耗并统计能耗表现。报告中主要引用 `tokens_per_joule`、`average_power_w`、`total_energy_j`、`completion_tokens` 和 `inference_duration_s`。 |
| `eval/ttft_bench.py` | TTFT 测试脚本，测试不同图片和 prompt 下的首 token 生成时延。报告中主要引用聚合及 `per_image` 的线性拟合结果。 |
| `eval/acc_bench.py` | 精度测试脚本，在 OCRBench sample30 数据集上逐条推理并统计正确率。报告中主要引用 `ratio_accuracy`、`n_correct` 和 `n_total`。 |

这些脚本均直接调用本地 PYNQ 硬件推理入口，不需要启动独立的 `llama-server`。
